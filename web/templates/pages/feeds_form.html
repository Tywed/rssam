Минимум 1 мин, максимум 10080 мин (7 суток).

Отправляет вебхук на каждую новую запись из этой ленты, независимо от фильтров. Настройте вебхуки в разделе «Вебхуки».

Включайте только для доверенных источников с отечественным центром сертификации (например, admkrai.krasnodar.ru). Действует только для этой ленты.

Автоматически удалять записи и хеши дедупликации старше указанного числа дней (по дате появления в rssam). Пусто — не удалять. Избранные записи не удаляются.

Новые записи сохраняются только как хеш для дедупликации; полный текст записывается при совпадении фильтра.

Telegram

Если выключено — прямой HTTP на t.me/s (может не работать без VPN).

Если задан — используется этот прокси вместо proxy-service.

Rutube

Лента видео канала Rutube. ID канала определяется из URL автоматически.

Max

Лента постов канала Max. URL вида https://max.ru/имя-канала.

VK Search

Подписка на результаты поиска VK, а не на группу или страницу.

  • vk-search://ваш запрос
  • https://vk.com/feed?section=search&q=ваш+запрос

Access token задаётся в настройках VK Search.

Dzen News

Подписка на поиск новостей Dzen, а не на канал или статью.

  • dzen-news://ваш запрос
  • https://dzen.ru/news/search?issue_tld=ru&sortby=date&text=ваш+запрос

Smotrim

Видео и сюжеты бренда на smotrim.ru (ранее api.vgtrk.com).

  • smotrim://67725 — brand ID (например, Вести. Кубань)
  • https://smotrim.ru/brand/67725
  • smotrim://67725?limit=50&type=plot — только сюжеты

RSS/Atom

Обычная RSS или Atom лента. URL должен указывать на XML/JSON feed, а не на страницу сайта.
