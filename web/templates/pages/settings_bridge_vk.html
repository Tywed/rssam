Как подписаться

VK Search — это не группа и не страница, а поиск постов через VK API newsfeed.search. Одна лента = один поисковый запрос.

Примеры URL при добавлении ленты:

  • vk-search://golang
  • https://vk.com/feed?section=search&q=golang

Запрос нормализуется (lowercase, схлопнутые пробелы). Для опроса нужен access token ниже.
