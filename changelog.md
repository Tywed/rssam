# Changelog

## Unreleased

## 0.1.5

- Безопасность: same-origin для cookie-запросов к `/v1` (мутации) и `/ws/v1`; SSRF-guard блокирует multicast/reserved и IPv4 внутри NAT64/6to4; логин с одинаковым временем ответа для неизвестного пользователя; пароль 8–72 (сервер, не только форма); служебные заголовки вебхуков не переопределяются.
- Производительность: `UPDATE sessions` не чаще раза в час; просроченные сессии удаляются cleanup'ом (миграция 0030); кэш вебхуков на пути refresh.

## 0.1.4

- Retention cleanup: типизация `$1::timestamptz` и удаление `feed_entry_dedup` по `(feed_id, hash)` — чистка снова выполняется.
- Свежая установка: `ADMIN_USERNAME`/`ADMIN_PASSWORD` пишутся на placeholder `users.id=1` (логин UI и `AUTH_TOKEN` — один тенант).
- WebSocket: Hijack через access-log, события только владельцу ленты, `subscribe`/reconnect в UI.
- Rate-limit: `TRUSTED_PROXIES` (по умолчанию loopback); чужой `X-Forwarded-For` игнорируется.
- RSS/Atom: лимит тела 16 MiB. Смена пароля требует текущий и отзывает прочие сессии. API-токен не в URL.
- Миграции под `pg_advisory_lock`. CI: `-race`, staticcheck, Postgres integration и smoke логина на отдельной БД.

## 0.1.3

- Подписки: вкладки «ошибки» и «неактивные» показывают ленты с пагинацией (раньше список был пустым — в выборке не было полей ошибок).
- Подписки: кнопка «Добавить» снова справа, рядом с экспортом OPML.
- Вебхуки: пауза/снятие с паузы из списка; статусы — кликабельные карточки, без второго ряда фильтров.
- Формы вебхука и фильтра: Сохранить / Назад / Удалить в одном ряду сверху.
- Состояние лент: массовый сброс автостопа на вкладке ошибок.
- Мосты: подписи настроек на русском; Max — параллельные слоты и пауза между запросами к API.
- Админка: «Хэшировать записи»; вебхук «хеш после доставки» ждёт завершения всех вебхуков записи.

## 0.1.2

- CSRF: если нет AUTH_TOKEN/METRICS_TOKEN, генерируется CSRF_SECRET и пишется в .env.
- API-токен больше не принимается из query string (`?token=`); только заголовок или сессия. WebSocket в UI по-прежнему через cookie.
- Retry вебхуков: потокобезопасный jitter, без panic на крошечных интервалах.
- Rate limit: вытеснение неактивных IP и потолок размера карты.
- Cleanup retention: удаление батчами, без одной длинной транзакции.
- Поиск: не роняет весь UI («search failed»); `plainto_tsquery` вместо `websearch_to_tsquery`.

## 0.1.1

- Telegram-вебхуки: превью ссылки включено по умолчанию.
- Админка: пауза/возобновление poller и webhook-воркеров без остановки HTTP/UI; удаление лент в ошибке или на паузе.
- Фильтры: в форме действий больше не путаются одинаковые ID меток и вебхуков.
- RSS: отдельный cookie jar на запрос, чтобы редиректы с Set-Cookie работали.
- Предупреждение о двух poller'ах считает только процесс `rssam`.
- Обновление из UI: модалка с логом, скачивание до остановки сервиса, User-Agent для GitHub, кнопка только если latest новее.

## 0.1.0

- Первая публичная выкладка исходников rssam (RSS-агрегатор: UI, фильтры, вебхуки, мосты).
